## 📌 About the project

This is my first GitHub project about video editing. In this project I will collect useful ideas and information about editing videos.

## 🎞️ Video editing

Some important parts of video editing are:
- ✂️ Cutting and arranging clips
- 🎵 Adding music and sound effects
- 📝 Adding text and subtitles
- 🎨 Using transitions and visual effects

## 📚 What I learned

I learned how to create a GitHub repository, edit a README file, use Markdown and save changes with commits.

## 😄 Fun fact

A short video can take much longer to edit than to record because every cut, transition and effect needs to be adjusted.
